文档 统一到产品范围、运行控制设计、运行时合同、用户手册及文档总索引；删除 114 个已追踪的旧过程/技术文档（106 个 reviews、8 个 technical），保留不可替代的正式验收、截图和历史 Git 链接。CHANGELOG 保留近期版本，旧全文链接到不可变基线。所有当前正式文档同步 HTML。
