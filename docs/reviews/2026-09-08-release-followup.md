## 本次补修与独立复核

原实现将产物导入异常折叠为普通 `agent failed ... exitCode=1`。现在由共享导入层产生受控诊断，区分 manifest、文件读取/路径、JSON、schema 和必需产物缺失；Claude、Codex、DSH adapter 将原因沿 `agent/error` 事件和 `node.interrupted` 审计传播，`tekon log` 可直接查看。摘要有固定错误码、500 字符上限及脱敏处理，仅保留必要文件/类型/字段或解析位置，不直接回显解析器携带的产物原文。JSON 序列化提示减少转义错误，不保证模型输出始终合法。

取消、超时、Codex 既有非零退出后的合法产物恢复、路径与敏感内容拒绝、Gate 及人工控制语义均保留。历史租约冲突没有写入性自动修复；手册明确确认退出不能裁决工作树身份，取消也不会清理租约。

独立审阅发现新预解析曾用 `trim()` 判断、却解析未去空白文本，错误拒绝带 BOM/NBSP 的原有合法产物。先补真实子进程导入回归，得到 2 失败/58 通过，再统一使用去空白结果，60 项全部通过；复查后必须修复项清零。原始诊断专项的首轮 RED 为 8 失败/208 通过；其中 Codex 缺产物用例曾误期待 schema 错误码，现按“缺必需产物”修正，该错误期望不作为 schema 缺陷证据。中间一轮还检出摘要 501 字符越界，现包含省略号在内不超过 500 字符。
