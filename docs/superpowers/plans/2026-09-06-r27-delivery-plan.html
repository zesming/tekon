2. 产品、设计与实现调整

2.1 排队暂停与恢复

保留 R27-01 的两条正常路径：暂停后初始 Job 排空而不执行，再显式恢复；认领前恢复则沿用原 Job。初评发现第三种交错：恢复读取 queued 后，另一 owner 认领并按 paused 排空，恢复随后解除暂停却返回已完成 Job，造成运行中但无执行者。

修复在现有 SQLite 写事务中复核原 Admission Job 的身份、所属 Run、queued 状态及 Run 非终态，并解除 paused。已被认领时保留 active-job 反馈，已排空时走现有正常恢复入队；不得用旧读取返回 enqueued，不得覆盖终态，不得同时创建两个活动 Job。优先复用现有原子入队能力，不增加暂停表、调度服务或新轮询器。确认参数仍由事务检查，不绕过上一代退出确认。

测试先行：确定性控制 queued 读取与 claim/drain 的顺序，证明基线丢失恢复；覆盖 workflow/goal、原 Job 身份、已有 active owner、排空后新 Job、取消/成功/失败赢家、失败回滚及独立连接竞争。真实 SQLite/默认执行器测试与真实进程 e2e 分别记录证明范围，mock 模型不冒充真实 Provider。

2.2 暂停与恢复反馈

所有使用 RunControls 的列表、详情和 Session 统一显示请求语义：暂停成功提示“暂停请求已记录，活动步骤将在边界停下”；恢复受理提示“已受理恢复，请观察原运行”。服务端拒绝或终态竞争仍显示真实结果；状态与控制入口由服务端快照刷新，不能由 Toast 推断模型已经开始或进程已经暂停。错误保留可见，禁止重复提交，在 320/390/768/1440px 与键盘交互验证通知不遮挡或越界。

2.3 真实交付证据

按报告 §6 增加一个真实 Claude 交付任务：隔离 Git 仓库、生产组合根和默认执行器，输出可验证 Artifact，运行真实构建 Gate，经过中断和显式恢复后检查原 Run/工作树/已完成节点及最终 Gate、Artifact、Audit 与 eval 结果。记录 Provider 版本、Run/Job、恢复与退出证据、命令结果及验证边界。没有真实 push/PR 的样本不得写成 readiness 全通过，不使用只读 smoke 替代交付任务。

3. 文档归并与清理

新增正式产品范围和运行控制设计文档；将已落地的 RunPlan、Admission、生命周期与 Harness 集成合同归并到现行技术文档，修正旧技术基线的过期判断。README、CHANGELOG、手册及其 HTML 同步当前行为；历史设计明确标为历史，不与现行合同竞争。

逐一核对 docs/superpowers/plans/，将仍有效的决策和验证合同迁入产品/技术/设计/手册后删除已完成过程计划。历史正式报告和可复验的脱敏证据保留；指向删除计划的历史引用改为固定 Git 快照，使历史证据可追溯。清理本轮拥有的临时脚本、输出和进程，不删除用户运行数据。执行方案评审与验收结论归档至本轮正式验收，最终删除本过程方案并保留固定提交链接。

4. 执行顺序与放行

  1. 独立 reviewer 与上游评估达成一致；本方案循环审查，无必须修复项后实施。原报告追加逐项批注，保留原作者结论与证据范围。
  2. Core 与 UI 分开所有权，先补回归并观察基线失败，再修实现、运行相关 e2e。主代理统一调度测试，同一测试/构建只保留一个活动执行。
  3. 独立 reviewer 对代码和测试一起审查，必须修复项处理后复查。
  4. 在最终代码执行 pnpm test --run、pnpm typecheck、pnpm lint、pnpm build、Core e2e、pnpm --filter @tekon/cli test:e2e 和全部 Chromium e2e（零重试）。四视口检查 Sessions、Session、Runs、Run、Approvals、Delivery、Config、Eval，保留截图及几何检查，并人工查看。交互包括受理、暂停/恢复/取消、审批、证据查看、配置、导航和错误恢复；浏览器矩阵不冒充真实读屏或其他 OS 验收。
  5. 执行真实 Provider 交付验证，归档本轮摘要和证据。文档检查链接、章节、占位及 Markdown/HTML 一致性，经 doc_reviewer 整体审阅并修正。
  6. 最终 reviewer 按原报告及用户 0–7 项逐项核对，未验证事项不得标完成。实现/验收放行后提交原 PR；更新 PR 描述，读取对应 Head 的全部 CI 终态，成功后按用户授权合并 main 并核对合并结果。

本轮采用 MINOR 0.25.0：修复恢复竞态及反馈，并补充用户手册的暂停、取消与恢复操作章节；按仓库版本规则，新增手册章节使用 MINOR。安装脚本未改时无需额外安装 smoketest。
