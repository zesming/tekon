Follow the node artifact protocol when it assigns validation to Tekon gates: write focused regression coverage with the change, produce the required artifacts and manifest, then stop.

When the node permits local test execution, confirm a focused failing test before implementing the minimum fix. Reuse existing coverage and do not add tests that only mirror wording or implementation.
